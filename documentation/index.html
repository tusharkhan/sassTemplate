WaveNode template documentation

Thank you for buying WaveNode. This file covers everything needed to get the template running, rebrand it and put it live. No prior build-tool experience is assumed — if you only want to change text and colours, you never need to run a command at all.

1. Getting started

The template is plain HTML, CSS and JavaScript. There is no framework, no server and no build step required to view or edit it.

The fastest possible start

Unzip the download and double-click index.html. It opens in your browser and works immediately, offline. Edit any .html file in a text editor and refresh.

To upload it, copy everything except the tools/, documentation/, src/ and node_modules/ folders to your web root. Those four are for development only; the site itself needs just the HTML files and the assets/ folder.

Recommended editors

Any text editor works. Visual Studio Code with the Tailwind CSS IntelliSense extension gives you autocomplete for the utility classes, which makes editing considerably faster.

4. Recompiling the CSS

The stylesheet ships pre-compiled, so you only need this section if you add new Tailwind utility classes or change tailwind.config.js. Editing existing text, swapping images or rearranging markup with classes already in use needs no rebuild.

Install Node.js 18 or newer, then from the template folder:

# install the one dev dependency (Tailwind CSS)
$ npm install

# rebuild the minified stylesheet once
$ npm run build

# or watch for changes while you work
$ npm run dev

Tailwind removes any class it cannot find in your files. If a style disappears after a rebuild, check that the content array in tailwind.config.js covers the file you added.

5. Colours and fonts

Re-skinning in two lines

The whole palette derives from two Tailwind colour scales. Change these in tailwind.config.js and rebuild:

colors: {
  primary: colors.indigo,   // try emerald, rose, violet…
  accent:  colors.cyan,
}

Two things are not driven by that config and need a manual pass if you change the brand hues: the glow shadows and .bg-glow gradients, which use literal RGB values in tailwind.config.js and src/input.css; and the inline logo gradient, which appears in every page's header and footer.

Dark and light themes

Dark is the default. The theme is a dark class on <html>, applied before first paint by a small inline script in every <head> so there is no flash of the wrong theme. The choice is remembered in localStorage under the key wavenode-theme.

To make light the default, remove class="dark" from the <html> tag on every page and invert the check in that inline script. To respect the visitor's operating-system preference instead, replace the condition with window.matchMedia('(prefers-color-scheme: dark)').

Swapping the fonts

Two self-hosted variable fonts are included: Plus Jakarta Sans for body text and JetBrains Mono for code. They are declared in assets/css/fonts.css and mapped in tailwind.config.js under fontFamily. Because both are variable fonts, one file per family covers every weight from 200 to 800.

Neither font is loaded from a CDN, so the template works fully offline and sends no requests to third parties.

6. JavaScript reference

All behaviour lives in one dependency-free file, assets/js/main.js. Every module is driven by data- attributes and exits quietly if its markup is absent, so you can delete any section of any page without causing an error.

Adding an accordion

<!-- one open at a time -->
<div data-accordion-group>
  <div class="card" data-accordion>
    <h3>
      <button type="button" data-accordion-trigger
              aria-expanded="false" aria-controls="p1">
        Your question
      </button>
    </h3>
    <div id="p1" class="accordion-panel" data-accordion-panel>
      <div><p class="px-6 pb-6">Your answer</p></div>
    </div>
  </div>
</div>

The inner <div> inside the panel is required — the open/close animation uses it.

8. Editing shared markup

The header and footer are physically duplicated into all 23 pages, which is what makes the template work with no server. The trade-off is that changing a navigation link by hand means editing 23 files identically.

The optional tools/ folder solves that. It is a small Python script (no packages needed) that assembles each page from shared parts:

# edit tools/partials/header.html once, then:
$ python3 tools/build.py       # rewrite all 23 pages
$ npm run build               # recompile the CSS

# check nothing has drifted out of sync
$ python3 tools/build.py --check

# regenerate sitemap.xml from the page list
$ python3 tools/make-sitemap.py

Page titles, meta descriptions and the canonical domain live in tools/pages.py and tools/build.py (SITE_URL). See tools/README.md for the full explanation.

Prefer to work by hand? Delete tools/ entirely and edit the HTML files directly. Nothing in the shipped site depends on it.

9. Launch checklist

The template ships with realistic placeholder content for a fictional company. Work through this list before going live — the first four items are the ones most often missed.

  1. 1

    Wire up the forms

    Every <form> uses action="#", which silently discards submissions. There are four: the footer newsletter (on every page), the contact form, the three auth forms, and the help-centre search. Point each at your own handler.

  2. 2

    Replace the legal pages

    terms.html and privacy.html are layout demonstrations, not legal advice. Both carry a visible amber warning — delete that warning block once a lawyer has supplied your real text.

  3. 3

    Remove the other template notices

    Three more visible notes are written for you, not your visitors: the demo-form note on contact.html, the demo-search note on help-center.html, and the placeholder-avatar note on about.html.

  4. 4

    Set your domain

    Every page has rel="canonical", og:url and og:image pointing at wavenode.io. Change SITE_URL in tools/build.py and rebuild, or find-and-replace across the HTML. Update robots.txt and sitemap.xml too.

  5. 5

    Replace the placeholder identity

    Swap the logo (inline SVG in each page's header and footer, plus assets/images/logo.svg and favicon.svg), the social card at assets/images/og-preview.png, and the 72 footer social links, which are all href="#".

  6. 6

    Replace the fictional contact details

    Search for @wavenode.io (seven addresses, including twelve mailto: links on the careers page) and wavenode.io for the API hostnames. The three office addresses on contact.html are invented, as are all people and customer names.

  7. 7

    Configure your 404

    404.html exists but your server must be told to serve it. On Apache add ErrorDocument 404 /404.html to .htaccess; on Nginx use error_page 404 /404.html;.

  8. 8

    Delete what you do not ship

    Upload the HTML files and assets/, robots.txt and sitemap.xml. Leave tools/, src/, documentation/, node_modules/ and the config files behind. Keep assets/fonts/OFL.txt — the font licence requires it.

11. Support

If something in the template does not behave as documented, please get in touch through the item's comments section on the marketplace. Including the page, the browser and a screenshot resolves almost everything on the first reply.

Support covers defects in the template and questions about how to use what is documented here. Customisation work, third-party integrations and bugs in your own modifications fall outside it — though we will usually point you in the right direction.
