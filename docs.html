Quickstart

Install the SDK, create a room server-side and join it from the browser. The snippet below is the whole integration — there is no separate signalling server to run.

Terminal

$ npm install @wavenode/sdk

server/create-room.js

import { WaveNode } from '@wavenode/sdk';

const wave = new WaveNode(process.env.WAVENODE_SECRET_KEY);

// Rooms are cheap — create one per broadcast.
const room = await wave.rooms.create({
  name: 'launch-event-2026',
  mode: 'broadcast',
  maxParticipants: 10000,
  ai: { captions: 'en', highlights: true },
  recording: { enabled: true, layout: 'active-speaker' }
});

// Hand this token to the browser. It expires in 60 minutes.
const token = await wave.tokens.publisher(room.id, {
  identity: 'host-rina',
  ttlSeconds: 3600
});

client/join.js

import { joinRoom } from '@wavenode/sdk/web';

const session = await joinRoom({ token });

await session.publishCamera({ resolution: '1080p' });
await session.publishMicrophone({ noiseSuppression: true });

session.on('caption', (line) => {
  captionEl.textContent = line.text;
});

Authentication

Server-side calls use your secret key as a bearer token. Browsers never see it — they get a short-lived, room-scoped JWT minted by your backend instead.

Never ship your secret key to the client. Keys are scoped to a project and can be rotated from the dashboard without downtime — old keys stay valid for one hour after rotation.

cURL

$ curl https://api.wavenode.io/v3/rooms \
    -H "Authorization: Bearer $WAVENODE_SECRET_KEY" \
    -H "Content-Type: application/json" \
    -d '{"name":"launch-event-2026","mode":"broadcast"}'

Client SDKs

All SDKs share the same method names, so the quickstart translates line for line.

@wavenode/sdk

JavaScript & TypeScript — Node 18+, Deno, Bun and every evergreen browser.

wavenode-python

Python 3.10+ with async support and typed response models.

WaveNodeKit

Swift package for iOS 16+ and macOS 13+, with SwiftUI view helpers.

wavenode-android

Kotlin SDK targeting API level 26 and above, Compose-friendly.

Rooms

A room is the container for a broadcast, meeting or audio session. Rooms are free until media flows through them.

  • POST /v3/rooms Create a room
  • GET /v3/rooms/:id Fetch a room and its participants
  • PATCH /v3/rooms/:id Update AI or recording settings mid-session
  • DELETE /v3/rooms/:id End the session and disconnect everyone

Request parameters

Parameters accepted when creating a room
Field Type Description
name string Human-readable identifier, unique within the project.
mode enum One of broadcast, meeting or audio.
maxParticipants integer Hard cap on concurrent joins. Defaults to your plan limit.
ai object Caption language, translation targets and highlight generation.
recording object Enable recording and pick a composition layout.

Tracks

Each published camera, microphone or screen share is a track. Subscribers choose which tracks to pull, so a viewer on a phone can take audio only without a separate stream.

Track events arrive on the same session socket as captions: trackPublished, trackUnpublished and trackQualityChanged.

Recordings

Recordings are written as they happen, so a session that ends abruptly still leaves a playable file. Composed MP4s and per-participant tracks are produced in parallel — request either or both.

Point storage.bucket at your own S3-compatible bucket to keep media entirely inside your infrastructure. We only store the manifest.

Webhooks

Every state change is delivered to your endpoint with an HMAC-SHA256 signature in the Wave-Signature header. Retries back off for up to 24 hours.

recording.ready

{
  "event": "recording.ready",
  "roomId": "rm_8Kd2mQ4xLp",
  "durationSeconds": 4360,
  "assets": {
    "composed": "https://cdn.wavenode.io/rec/8Kd2mQ4xLp.mp4",
    "transcript": "https://cdn.wavenode.io/rec/8Kd2mQ4xLp.vtt",
    "highlights": 7
  }
}

Errors

Errors use conventional HTTP status codes and always include a machine-readable code alongside the message.

Common API error codes
Status Code Meaning
401 invalid_key Secret key missing, malformed or rotated out.
403 token_expired The room JWT is past its TTL. Mint a new one.
409 room_name_taken Another active room in this project uses that name.
429 rate_limited Back off and retry after the Retry-After header.

Rate limits

Control-plane calls are limited to 100 requests per second per project, burstable to 300. Media itself is never rate limited — publishing and subscribing are governed by your plan allowance, not by request counts.
